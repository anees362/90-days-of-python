# Day 14 - Tuples

## What I Learned
- What tuples are and how to create them.
- Accessing tuple items using indexes.
- Tuples are immutable (cannot be changed).
- Finding the number of items using `len()`.
- Counting values using `count()`.
- Finding item positions using `index()`.
- Tuple slicing.
- Looping through tuples using `for` loops.
- Creating single-item tuples.
- Tuple unpacking.
- Using `sum()`, `max()`, and `min()` with tuples.
- Calculating averages using tuples.
- Using conditions with tuple data.
