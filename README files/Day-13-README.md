# Day 13 - Lists

## What I Learned
- What lists are and how to create them.
- Accessing list items using indexes.
- Adding items using `append()` and `insert()`.
- Removing items using `remove()` and `pop()`.
- Counting items using `len()`.
- Sorting lists using `sort()`.
- Reversing lists using `reverse()`.
- Negative indexing.
- List slicing.
- Looping through lists using `for` loops.
- Updating list items.

## Practice Exercises
1. Created lists of games and characters.
2. Practised adding, removing, and replacing list items.
3. Used indexing and slicing to access items.
4. Used loops to print list items.
5. Created a student list program.
