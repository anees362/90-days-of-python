# Day 5 - Input Validation & Error Handling

## Topics Learned
- Input validation
- try and except
- ValueError handling
- Conditional statements
- Handling invalid user input

## Exercises

### Exercise 1 - Safe Number Input
- Ask the user for a number.
- Convert the input into an integer.
- Handle invalid input using try and except.

### Exercise 2 - Age Checker
- Ask the user for their age.
- Check whether they are a child or an adult.
- Handle invalid input.

### Exercise 3 - Positive Number Checker
- Check whether a number is negative, zero, or positive.
- Handle invalid input.

## Mini Project - Number Guessing Game
- Generate a random number between 1 and 10.
- Give the player 5 attempts.
- Tell the player to guess higher or lower.
- Handle invalid input.
- Display a message when the player wins or runs out of attempts.

## What I Learned
- How to use try and except.
- How to handle ValueError.
- How to validate user input.
- How to use for-else loops.
- How to improve error handling in Python programs.
