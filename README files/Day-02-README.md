# Day 2 – Comparison Operators

## Exercise 1: Predict the Output
Practised comparison operators:
- Greater than (`>`)
- Less than (`<`)
- Equal to (`==`)
- Not equal to (`!=`)

## Exercise 2: Age Registration
Created a program that:
- Asks the user for their age.
- Checks whether they are 18 or older.
- Displays whether they can register.

## Exercise 3: Grading Program
Created a grading program using conditional statements:
- Marks 90 or above → Grade A
- Marks 75 or above → Grade B
- Marks 50 or above → Grade C
- Below 50 → Grade F

## What I Learned
- How comparison operators work.
- How to use `if`, `elif`, and `else`.
- How to build programs using conditions.
